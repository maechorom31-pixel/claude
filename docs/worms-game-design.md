# 웜즈(Worms) 스타일 게임 — 게임 디자인 문서 (GDD)

> 버전 0.1 · 턴제 2D 포격(artillery) 전략 게임 설계
> 목적: 이후 구현(코드)의 기준이 되는 단일 설계 문서

---

## 1. 개요 (Overview)

| 항목 | 내용 |
|------|------|
| 장르 | 턴제(Turn-based) 2D 포격/전략 |
| 시점 | 2D 측면 뷰(side-view) |
| 핵심 루프 | 조준 → 발사 → 지형 파괴 → 턴 종료 → 상대 턴 |
| 플레이어 수 | 2~4팀 (로컬 핫시트 우선, 이후 네트워크) |
| 승리 조건 | 마지막까지 살아남은 팀 |
| 분위기 | 코믹·과장된 폭력, 가벼운 톤 |

### 1.1 핵심 재미 요소 (Pillars)
1. **물리 기반 조준** — 각도, 힘, 바람, 중력을 읽어 포물선을 계산하는 손맛.
2. **파괴 가능한 지형** — 지형이 무기에 의해 실시간으로 깎이고 무너진다.
3. **턴제 긴장감** — 제한 시간 안에 한 마리만 행동, 실수가 곧 손해.
4. **다양한 무기** — 직관적인 바주카부터 황당한 양 폭탄까지 표현력 있는 무기고.

## 2. 게임플레이 (Core Gameplay)

### 2.1 턴 구조
```
라운드 시작
 └─ 팀 A 턴
     ├─ 활성 웜 1마리 선택(또는 자동 순환)
     ├─ 이동 단계: 좌우 이동, 점프, 백플립
     ├─ 행동 단계: 무기/도구 1회 사용
     ├─ 턴 타이머(예: 45초) 또는 무기 발사 후 후처리 시간(예: 3초)
     └─ 턴 종료 → 모든 발사체/물리 정지 대기(retreat time)
 └─ 팀 B 턴 …
```

- **턴 타이머**: 기본 45초. 무기를 발사하면 "후퇴 시간(retreat time)" 3~5초가 주어진 뒤 강제 종료.
- **한 턴 = 한 행동**: 이동은 자유롭되 공격/도구는 원칙적으로 1회. (특정 무기는 예외 — 예: 저격 후 이동 불가)
- **물리 정착 대기**: 발사체·낙하·연쇄 폭발이 모두 멈출 때까지 다음 턴 시작을 보류.

### 2.2 웜(캐릭터) 상태
- 체력(HP): 기본 100.
- 낙하 데미지: 일정 높이 이상 낙하 시 `floor((낙하높이 - 임계값) * 계수)`.
- 물 빠짐: 화면 하단 수면 아래로 떨어지면 **즉사**.
- 넉백: 폭발 중심에서 거리에 반비례한 충격으로 밀려남(지형 충돌 시 추가 낙하 데미지 가능).

### 2.3 조준 & 발사 모델
- **각도**: 0~360°, 보통 위/아래 키로 미세 조정.
- **파워**: 스페이스바를 누르는 시간으로 충전(0~100%).
- **바람**: 매 턴 무작위로 변경(-10 ~ +10). 영향받는 무기(바주카, 수류탄 등)와 무시하는 무기(총류) 구분.
- **궤적**: `v = power * dir`, 매 틱마다 `v += gravity + wind(해당무기)`, `pos += v`.
- 조준 보조선(선택): 예상 궤적 점선 표시 여부는 난이도 옵션.

## 3. 지형 시스템 (Destructible Terrain)

핵심 기술 요소. 권장 구현은 **비트맵 마스크 방식**.

- 지형을 1채널 마스크(예: `solid[x][y] = 0|1`)로 보관.
- 폭발 시 중심 `(cx, cy)`, 반지름 `r`의 원 안을 `0`으로 클리어.
- 렌더링은 마스크 + 텍스처(컬러맵)를 합성.
- **떨어지는 지형(선택)**: 클리어 후 떠 있는(아래 지지가 없는) 픽셀 덩어리를 낙하시킬지 여부 → 1차 버전은 생략 가능.
- 충돌 판정: 웜/발사체의 발밑·진행 경로 픽셀이 `solid`인지 검사.

```
폭발(cx, cy, r):
    for x in [cx-r, cx+r]:
        for y in [cy-r, cy+r]:
            if (x-cx)^2 + (y-cy)^2 <= r^2:
                solid[x][y] = 0   # 지형 제거
    데미지 적용(원 영향권 내 웜에게 거리 기반 데미지 + 넉백)
```

## 4. 무기 & 도구 (Arsenal)

### 4.1 1차 버전 핵심 무기고 (MVP)
| 무기 | 분류 | 바람 영향 | 특징 |
|------|------|:---:|------|
| 바주카(Bazooka) | 발사체 | O | 포물선, 직접 명중 시 폭발 |
| 수류탄(Grenade) | 투척 | O | 퓨즈 타이머(1~5초), 튕김(bounce) |
| 산탄총(Shotgun) | 직사 | X | 2발, 즉발 히트스캔 |
| 다이너마이트(Dynamite) | 설치 | X | 발밑 설치, 짧은 퓨즈, 강력 |
| 공성 박치기/근접(Fire Punch) | 근접 | X | 강한 넉백, 데미지 |
| 점프 로프/순간이동(선택) | 이동 도구 | X | 위치 이동 |

### 4.2 확장 무기 (시그니처)
- **양 폭탄(Sheep)**: 좌우로 굴러가다 폭발.
- **공중 폭격(Air Strike)**: 좌표 지정, 상공에서 미사일 다발 투하(바람 영향).
- **홀리 핸드 그레네이드(Holy Hand Grenade)**: 초강력 광역.
- **콘크리트 당나귀(Concrete Donkey)**: 위에서 떨어지며 지형을 관통/파괴.
- **닌자 로프(Ninja Rope)**: 고급 이동 — 스윙 기동.

### 4.3 도구
- 삽/곡괭이 등 근접 굴착, 공기 보급(낙하산), 텔레포트, 백팩(보급 상자).

### 4.4 무기 데이터 스키마 (구현 대비)
```json
{
  "id": "bazooka",
  "name": "바주카",
  "category": "projectile",
  "damage": 45,
  "blastRadius": 50,
  "affectedByWind": true,
  "fuse": null,
  "knockback": 1.0,
  "ammo": -1,          // -1 = 무제한
  "usesPerTurn": 1
}
```

## 5. 맵 & 환경 (Maps)

- **수위(Water Line)**: 맵 하단 수면. 아래로 떨어지면 즉사.
- **맵 생성**: (a) 손으로 그린 마스크 이미지 로딩, (b) 절차적 생성(노이즈 기반 언덕/동굴).
- **오브젝트**: 지뢰(Mine — 근처 접근 시 퓨즈 후 폭발), 폭발 드럼통(Oil Drum — 연쇄 폭발), 보급 상자.
- **서든 데스(Sudden Death)**: 일정 라운드 경과 후 발동 → 모든 웜 HP를 1로 만들거나 수위가 매 턴 상승.

## 6. 팀 & 진영 (Teams)

- 팀당 웜 1~8마리(기본 4).
- 팀 색상/이름 커스터마이즈.
- 턴 순서: 팀 라운드로빈, 팀 내 웜은 순차 또는 선택.
- 전멸한 팀 탈락, 마지막 생존 팀 승리. (동시 전멸 시 무승부)

---

## 7. UI / UX

- **상단**: 현재 팀/웜, 바람 게이지, 턴 타이머.
- **하단/측면**: 선택 무기, 파워 게이지, 각도 인디케이터.
- **무기 선택**: 카테고리 그리드(라디얼 또는 격자 메뉴).
- **피드백**: 데미지 숫자 팝업, 폭발 파티클, 화면 흔들림(screen shake), 사운드(발사/폭발/물빠짐/승리).
- **접근성**: 조준 보조선 토글, 색맹 친화 팀 색상.

## 9. 기술 아키텍처 (구현 대비)

### 9.1 권장 모듈 구조
```
core/
  game_state      # 팀/웜/턴/승패 상태 머신
  turn_manager    # 턴 진행, 타이머, 후퇴 시간
physics/
  integrator      # 중력/바람/속도 적분(고정 타임스텝)
  collision       # 지형 마스크 ↔ 엔티티 충돌
terrain/
  terrain_mask    # solid 비트맵, 폭발 클리어, 렌더 합성
weapons/
  weapon_defs     # 데이터 정의(JSON)
  projectile      # 발사체 생애주기, 폭발 처리
entities/
  worm            # HP/위치/상태
render/
  renderer        # 지형/엔티티/UI 그리기
  camera          # 추적/줌
input/
  input_handler   # 키 매핑 → 의도(intent)
audio/
ui/
```

### 9.2 핵심 설계 원칙
- **고정 타임스텝 물리 루프**(예: 60Hz)로 결정론 확보 → 향후 네트워크 동기화·리플레이에 유리.
- 데이터 주도 무기 정의(JSON) → 밸런스 조정이 코드 수정 없이 가능.
- 렌더와 시뮬 분리.
- 결정론적 RNG(시드 고정) → 바람/맵 재현 가능.

### 9.3 후보 기술 스택
| 스택 | 장점 | 적합 |
|------|------|------|
| Python + Pygame | 빠른 프로토타이핑, 직관적 픽셀 조작 | 학습/MVP |
| JavaScript + HTML5 Canvas | 브라우저 즉시 실행, 공유 쉬움 | 데모/멀티 확장 |
| TypeScript + Phaser | 게임 프레임워크 기능 풍부 | 본격 웹게임 |

> 스택은 미정. MVP는 Pygame 또는 Canvas 권장.

## 10. 밸런스 가이드 (초안 수치)

| 파라미터 | 기본값 |
|---------|-------|
| 웜 HP | 100 |
| 턴 타이머 | 45초 |
| 후퇴 시간 | 3초 |
| 중력 | 0.3 px/tick² (60Hz 기준) |
| 바람 범위 | -10 ~ +10 |
| 바주카 데미지/반경 | 45 / 50px |
| 수류탄 데미지/반경 | 50 / 45px |
| 낙하 데미지 임계 | 낙하 > 100px 부터, 계수 0.3 |
| 서든 데스 발동 | 15라운드 후 |

> 모든 수치는 플레이테스트로 조정. 데이터 파일로 분리해 핫리로드 가능하게 한다.

## 11. 개발 로드맵 (Milestones)

**M1 — 코어 루프 (플레이 가능 최소)**
- 지형 마스크 + 렌더, 웜 배치/이동/점프, 턴 매니저, 바주카 1종, 폭발·지형 파괴·데미지, 승패 판정.

**M2 — 무기고 & 환경**
- MVP 무기 6종, 바람, 수류탄 퓨즈/바운스, 물빠짐 즉사, 낙하 데미지, 무기 선택 UI.

**M3 — 폴리시 & 콘텐츠**
- 시그니처 무기, 절차적 맵, 보급 상자/지뢰/드럼통, 사운드/파티클/화면 흔들림, 서든 데스.

**M4 — 멀티플레이/확장 (선택)**
- 결정론적 락스텝 또는 서버 권위 네트워크, 리플레이, 맵 에디터.
