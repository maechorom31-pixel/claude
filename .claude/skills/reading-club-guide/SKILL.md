# 독서모임 차시 지도안 생성

교사가 학생들과 책을 나눠 읽고 여러 차례 모이는 독서모임의 차시별 토론 지도안을 만든다.
산출물은 **항상 인쇄용 최종본**이다. 초안·해설·부연 없이 바로 출력해서 쓸 수 있는 형태로 작성한다.

## 입력으로 확인할 것

사용자 메시지에서 다음을 파악하고, 없으면 합리적으로 가정하되 가정을 한 줄로 명시한다:

- 책 제목과 이번 차시의 읽기 범위 (예: 1부, 1~2부)
- 몇 번째 모임인지 / 총 몇 회 모임인지
- 모임 시간 (기본값: 90분)
- 학생 연령대 (기본값: 중고등학생)
- 사용자가 직접 언급한 인상·관점·문제의식 — **있으면 반드시 지도안의 중심으로 삼는다.**
  사용자의 생각을 다듬어 발문으로 승격시키고, 일반론은 보조로 밀어낸다.

## 형식 규칙 (사용자가 반복 요청한 것 — 기본 내장)

1. **분량 절제**: 주제는 4~6개, A4 1~2장 분량. 많이 담는 것보다 발언이 많이 나오는 것이 목표.
2. **질문 중심**: 각 주제는 배경 설명 1~3줄 + 발문 2~4개. 설명문 단락 금지.
3. **발문의 질**:
   - 예/아니오로 끝나지 않고 입장을 요구하는 질문
   - 학생 자신의 경험과 연결되는 질문을 주제당 1개 이상 (단, 개인 경험 공개를 강요하지 않도록 표현 주의)
   - 핵심 발문은 **굵게** 표시
4. **누적 구조**: 여러 차례 모이는 모임이면,
   - 도입부에 지난 차시 과제/메모를 꺼내 비교하는 활동을 넣는다
   - 마무리에 다음 차시로 이어지는 메모 과제를 넣는다 (다음 차시에서 회수할 것)
   - 마지막 차시는 1차시의 메모로 되돌아가 "내 생각이 달라졌는가"로 닫는다
5. **스포일러 통제**: 학생들이 이번 차시 범위까지만 읽었다고 가정한다. 이후 내용은 발문에 노출하지 않되, 복선은 "이상하지 않나요?" 수준의 미스터리로만 던진다.
6. **문서 구성 순서**: 차시 흐름(시간 배분 표) → 도입 활동 → 주제별 발문 → 마무리 과제 → 핵심 질문 요약표
7. **검증**: 작성한 발문을 출력 전에 한 번 자체 점검한다 — 주어가 둘 이상 얽혀 뜻이 모호해진 문장, 의도와 반대로 읽힐 수 있는 문장은 고쳐 쓴다.

## 내용 원칙

- 작품 정보(줄거리 요약)는 지도안에 넣지 않는다. 교사는 이미 읽었다. 발문에 필요한 최소 맥락만 1~3줄.
- 번역본이 여럿인 작품은 한국어 통용 번역본(출판사·역자)을 웹에서 확인하고, 번역 특유의 어휘가 논점이 되면 그것을 발문 소재로 활용한다.
- 수위 높은 작품은 지도안 말미에 교사용 주의 메모를 한 줄 넣는다 (다룰 장면 선별 권고 등).
- 교사용 팁이 필요하면 인용구(>) 한 줄로만. 본문과 섞지 않는다.

## 출력 후

- 문서 파일로 저장해 달라는 요청이 없으면 채팅 응답으로만 출력한다.
- 여러 차시를 한 문서로 합치는 옵션을 마지막에 한 줄로 제안한다.
