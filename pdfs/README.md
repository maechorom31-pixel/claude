# 여기에 시험지 PDF를 올리세요

GitHub 웹에서: 이 폴더 열기 → **Add file → Upload files** → PDF 끌어다 놓기 → Commit.

1~2분 뒤 자동으로:
- 문항이 분리되어 색인에 쌓이고 (`data/archive.jsonl.gz`)
- 처리 결과가 `data/REPORT.md` 에 적히고
- 검색 페이지가 다시 만들어집니다.

같은 파일을 두 번 올려도 내용으로 알아보고 건너뛰니 걱정 없이 올리면 됩니다.

**과목·연도를 못 읽었다고 REPORT 에 나오면** — 파일명에 넣어서 이름만 바꾸세요.
예: `2026_7월학평_물리학1.pdf`. 다음 실행에서 자동으로 채워집니다.

**용량이 걱정되면** — 오래된 PDF는 지워도 됩니다. 추출된 텍스트·검색·용례는
`data/archive.jsonl.gz` 에 남아 그대로 동작하고, 그 시험지의 지면 이미지만
빠집니다.
