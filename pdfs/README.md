# 여기에 시험지 PDF를 올리세요

파일 이름만 **`연도_시험_과목`** 으로 맞추면 됩니다.

```
2026_대수능_생명과학1.pdf
2027_6월모평_국어.pdf
```

- **연도 폴더는 만들 필요 없습니다.** 여기(pdfs/)에 그냥 올리면 봇이
  연도 폴더를 만들어 정리합니다. 새 연도가 나와도 마찬가지입니다.
  저장소 맨 위에 잘못 올려도 봇이 거둬 갑니다.
- 세 번째 칸(과목)은 표지 판독보다 우선합니다. 약어(생윤·사문·물1·언매…)도 됩니다.
- 같은 파일을 두 번 올려도 내용으로 알아보고 건너뜁니다.
- 스캔본(글자가 안 긁히는 PDF)은 문항을 못 읽습니다. 처리 결과는
  1~2분 뒤 `data/REPORT.md` 에 적힙니다 — **보유 현황** 표에서 어느
  시험·과목이 올라왔고 뭐가 빠졌는지 볼 수 있습니다.

**과목이 잘못 잡혔으면** — 그 파일을 지우고 `연도_시험_과목` 이름으로 다시
올리세요. 다음 실행에서 덮어씁니다.

**한 연도만 다시 파싱하려면** — Actions → 기출 색인 갱신 → Run workflow 에서
`target` 에 연도(예: 2027)를 넣고 실행.

**잘못 올린 파일을 완전히 빼려면** — PDF 삭제 후 Run workflow 에서 `prune` 을
켜고 실행. (그냥 지우기만 하면 검색 데이터는 남습니다 — 용량 정리용 동작.)
